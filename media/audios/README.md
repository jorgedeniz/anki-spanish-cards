# 🔊 Audios

Los audios generados por el pipeline **no se guardan aquí**. Viven en
Azure Blob Storage, contenedor `anki-vocab-media`, prefijo `audios/`.

Esta carpeta existe solo para mantener la estructura del proyecto visible
en el repositorio — `scripts/async_media_client.py` sube directamente a
la nube, sin pasar por disco local.
